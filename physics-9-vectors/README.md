# Векторы для 9 класса

Векторы «с нуля» для математики и физики 9 класса — одна страница с двумя вкладками. К каждому понятию — рисунок на клетчатой плоскости, в конце разделов — вопросы для самопроверки.

Сайт: https://verter73.github.io/physics-9-vectors/

| Вкладка | Что внутри |
|---|---|
| Математика | что такое вектор (обозначение, модуль, масштаб, равные, противоположные и коллинеарные векторы); проекции на оси, их знак, модуль по теореме Пифагора, проекции через угол; сложение по правилам треугольника и параллелограмма, через проекции, вычитание, умножение на число |
| Физика | скалярные и векторные величины; задачи с разбором: перемещение туриста, лодка на реке, равнодействующая сил; задачи для самопроверки |

Ссылка сразу на вкладку: `#mat` или `#fiz` в конце адреса.

Статичная страница без сборки: `index.html`, общий `style.css`, рисунки строит `vector.js` из данных в атрибуте `data-vec`.

Все учебные страницы: https://verter73.github.io/school-pages/
