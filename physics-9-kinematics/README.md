# Кинематика для 9 класса

Шесть задач на равноускоренное движение с разбором «с нуля»: теория, картинка, решение по шагам, ответ и вопрос для самопроверки.

Сайт: https://verter73.github.io/physics-9-kinematics/

| Задача | О чём |
|---|---|
| 1 | Путь и перемещение, две средние скорости |
| 2 | Торможение шайбы: когда скорость станет нулём |
| 3 | Ускорение самолёта по изменению скорости |
| 4 | Три графика скорости в одних осях |
| 5 | Ускорение и закон скорости по графику, график aₓ(t) |
| 6 | Автобус: разгон, равномерное движение, торможение |

Статичные страницы без сборки: `index.html`, `zadacha-1.html` … `zadacha-6.html`, общий `style.css`, графики рисует `graph.js` из данных в атрибуте `data-graph`.
