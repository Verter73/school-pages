# Равноускоренное движение: справочник к СР 3 — 9 класс

Разбор справочного листа к самостоятельной работе 3. Все 11 пунктов связаны одним стержнем: ускорение не меняется (aₓ = const), а три графика aₓ(t), vₓ(t), x(t) связаны двумя действиями — площадью под графиком (вперёд по цепочке) и наклоном графика (назад).

Сайт: https://verter73.github.io/school-pages/physics-9-sr3/

| Страница | Пункты справочника | О чём |
|---|---|---|
| `index.html` | все | Карта-стержень, живая модель, таблица «где что» |
| `shag-1.html` | 1 | Ускорение, проекция и модуль, единица м/с² |
| `shag-2.html` | 2, 5, 7 | Закон скорости, графики aₓ(t) и vₓ(t), ускорение по наклону |
| `shag-3.html` | 3, 6, 8 | Перемещение — площадь; три формулы из одной трапеции; путь |
| `shag-4.html` | 4, 5, 6, 9, 10, 11 | Уравнение движения, парабола, скорость и путь по x(t), события |

Статичные страницы без сборки. Общий стиль `style.css` и графики `graph.js`, `declutter.js` — копии из скилла school-physics. Анимация — `motion.js` + `motion.css`: блок `<div class="motion" data-motion='JSON'>` рисует тело на оси и синхронные графики с ползунками x₀, v₀ₓ, aₓ.
